What changes when the biology stays the same, but the experimental batch changes?

This study asks whether acquisition differences between experiments make the same perturbation harder to recognize—and whether a mixture-of-experts model handles that shift better than an equally controlled dense model.

The order matters: first understand the data and measure batch difficulty, then prove the models can learn, and only then compare dense versus MoE.

What is one example? How are splits made? What is difficulty? What do we know? What happens next?

The study in four facts

A deliberately narrow substrate

Restricting the first study to one cell type makes the batch question easier to interpret. Cell type is not allowed to masquerade as batch difficulty.

1 cell typeHUVEC only. RPE, HepG2, and U2OS are outside this first analysis.
24 experimentsEach experiment is treated as a distinct acquisition environment or batch.
1,108 classesTreatment perturbations only. Positive and negative controls are excluded from the classification labels.
6 channelsThe end-to-end model receives all six native grayscale acquisitions for each microscope site.
Approximate scale: the complete design has a ceiling of 24 × 1,108 = 26,592 treatment wells and about twice as many microscope sites. The frozen manifest records the real total because a small number of experiment–perturbation combinations or sites can be missing.

Data anatomy

From experiment to model input

The words “experiment,” “well,” “site,” and “channel” refer to different levels. Confusing them changes what a split or an accuracy number means.

1

Experiment

One acquisition environment. Different dates, plates, instruments, reagents, or handling can create a batch signature.

2

Plate

A physical multi-well plate inside an experiment. Plate identity is nested within the larger experiment batch.

3

Well

One treatment is applied to the cells in this physical well.

4

Two sites

Two microscope fields from different locations in the same well. They are related views, not two independent treatments.

5

Six channels/site

The six grayscale channels are stacked into a single six-channel tensor.

Training unit: site

A site is one model example. Both sites from a well have the same perturbation label, but each must be recognizable on its own. The new certification gate therefore uses full, unaugmented site accuracy.

Secondary summary: well

For a well-level number, the two site logits can be averaged before making one prediction. That can reduce field-of-view noise, but it can also hide one bad site. We now report site and well results side by side.

Isolation by design

The target experiment is not a validation set

The main split is made by experiment, while the source-IID split is made by whole wells. Both sites from the same well always stay together.

One primary fold

Source trainingMost treatment wells from 16 source experiments. Used for normalization and supervised learning.
Source IIDWhole source wells held out per perturbation. Used for checkpoint selection.
8 target experimentsEntire experiments held out. Used only for the final batch-shift measurement.

Across the three primary folds, every one of the 24 experiments serves as a target exactly once, with 16 source and 8 target experiments per fold.

The target is excluded from

  • Image normalization statistics
  • Supervised training
  • Source-IID validation
  • Checkpoint and recipe selection
  • Masked-autoencoder pretraining

Why not use the WILDS split for everything?

The custom folds let us ask more specific questions: which experiment is hard, whether independently measured distance predicts performance, and what happens when the target stays fixed but the source experiments change.

The WILDS split can remain an external reference; it is not the only way to study the acquisition structure.

Independent difficulty measurement

Difficulty is perturbation-matched embedding shift

Cell-DINO is used here as a frozen measuring instrument, not as the initialization for the end-to-end model comparison.

1. Match one class

Take perturbation c in target experiment t. Find the same perturbation in every selected source experiment.

→

2. Compare embeddings

Compute the source centroid for that perturbation, then compare it with the target well embedding.

d(c,t) = 1 − cosine(target, source centroid)
→

3. Summarize the split

Repeat across shared perturbations and take the median. A larger number means the same biology looks more different across batches.

Important: the calculation begins per perturbation, but the current registry stores one median difficulty per target/source split. A stronger follow-up will retain the full per-class distribution and ask whether high-shift classes are the ones the raw model misses.

Natural held-out folds

The 24 experiments are balanced into three groups using their Cell-DINO centrality. Each group becomes an eight-experiment target fold in turn.

Controlled source resampling

For a fixed target experiment, twelve source experiments are selected from low, medium, or high distance tiers. The target images and source count stay fixed; only source composition changes. Three resamples support cheap probes, while the raw-image screen uses one per tier for speed.

Current certification gate

What “the recipe passed” actually means

≥ 80%

Full unaugmented training-site accuracy

Measured on every individual source training site, not hidden by averaging two sites into a well.

→

Then select using source IID

Among eligible checkpoints, source-IID performance selects the checkpoint. Target accuracy is never consulted. If no bounded recipe passes, the state is exhausted and the comparison remains blocked.

Online signal

Augmented site accuracy and loss update each epoch. They should improve overall but need not be monotonic.

Gate signal

Full unaugmented site and well accuracies are measured every five epochs. Site accuracy is the default gate.

Six candidates

Three ResNet and three ViT recipes run in parallel across six GPUs. Finishing first does not make a recipe best; source-IID performance breaks the tie among passing recipes.

Interpretation guardrails

What each result would—and would not—show

Evidence for a batch-difficulty effect

  • A trained model performs worse on independently measured harder targets.
  • The relationship appears at both aggregate and per-perturbation levels.
  • With the target fixed, changing only source composition changes performance in the predicted direction.

Evidence that MoE helps

  • Dense and MoE models both pass the same learning gate.
  • They use the same splits, recipe, checkpoint rule, and active-compute budget.
  • MoE improves target accuracy or the difficulty slope across more than one frozen split.
Not the premise: the study does not require batch information to be removed from the representation. The claim of interest is narrower: whether measured acquisition shift predicts difficulty, and whether conditional capacity improves perturbation recognition under that shift.

Why did the small canary pass while full training failed?

The canary proved that the model and optimizer could memorize a small, simplified subset without the full regularization and variability. It did not prove that the production recipe could optimize the complete multi-experiment task. That is why the new gate operates on the full source fold.

Why not average the two sites during training?

Site-level training gives the model more observations and requires each field to carry the signal. Keeping both sites in the same split prevents leakage. Well-level averaging remains useful as a secondary robustness summary.

Does an 80% training threshold guarantee good target performance?

No. It only removes severe underfitting as the dominant explanation. Generalization can still be poor, which is exactly what the held-out experiment analysis is designed to measure.

Study status: data, embeddings, folds, and preliminary probes are frozen. The original raw-image screen was stopped for underfitting. Full-data recipe certification is the active gate before raw-image difficulty confirmation or dense-versus-MoE comparison.
