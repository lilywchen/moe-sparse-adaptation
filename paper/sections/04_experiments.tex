\section{Experimental design}

\subsection{RxRx1 acquisition shift}
RxRx1 contains 1,139 siRNA perturbations repeated across fluorescence-microscopy experiments. We
use the official WILDS split \citep{koh2021wilds}: 33 training experiments, held-out images from
those experiments for ID evaluation, four complete experiments for OOD validation, and 14
experiments reserved for one confirmatory OOD-test evaluation. Geometric augmentation is shared
across methods. Photometric augmentation is excluded because it directly manipulates the
acquisition signal under study.

\subsection{Stage-0 instrument qualification}
Low OOD accuracy is uninterpretable if the dense model cannot learn the perturbation task. We
therefore record train, ID, OOD-validation, and worst-experiment accuracy before any sparse model.
Natural-image DINOv2 ViT-S/14 failed a bounded rescue: its best official-preprocessing arm reached
5.50\% OOD-validation and 10.53\% ID accuracy, versus 15.42\% and 24.58\% for a validation-only
canonical WILDS ResNet-50 sanity reference. It was excluded before MoE experiments.

We next evaluated the released Cell-DINO CP ViT-S/8 using the WILDS three-channel composite mapped
to five pretrained slots with RNA and mitochondria zero-filled. After correcting the published
downstream representation to concatenate the normalized class token and mean normalized patch
token, the best full-fine-tuned arm reaches 17.76\% train, 11.16\% ID, 5.93\% OOD-validation, and
1.26\% worst-experiment accuracy. All values are from OOD-validation selection with OOD test
untouched. This instrument also fails the frozen competence boundary; it is not an MoE result.

The final bounded qualification uses the official six grayscale acquisitions. For Cell-DINO we
compare a frozen five-epoch linear probe with ten-epoch full fine-tuning at $10^{-4}$ using the
fixed biological map
$[w1,w2,w4,\operatorname{mean}(w3,w6),w5]$ to DNA, ER, RNA, AGP, and mitochondria.
The frozen model reaches 10.62\% train, 7.64\% ID, and 4.42\% OOD-validation accuracy; full
fine-tuning reaches 39.00\%, 27.09\%, and 12.29\%, respectively. Full adaptation is therefore in
the canonical WILDS sanity range while leaving a 14.80-point ID--OOD gap. This establishes a
competent batch-transfer instrument and licenses the matched kill comparison; it is not evidence
that MoE helps.

We retain Channel-Adaptive DINO ViT-L/16 on native $w1\ldots w6$ using its Bag-of-Channels input as
a mapping-free instrument diagnostic once its distinct approved checkpoint is available. It is
not required for the matched Cell-DINO contrast. The fixed map reflects the Cell Painting
acquisition in which phalloidin (actin) and WGA (Golgi/plasma membrane) share the AGP channel.
All qualification values use OOD-validation selection and leave OOD test untouched.

The bounded native interfaces are therefore:
\begin{enumerate}
  \item Cell-DINO CP ViT-S/8 with the fixed biological map
  $[w1,w2,w4,\operatorname{mean}(w3,w6),w5]$ to DNA, ER, RNA, AGP, and mitochondria;
  \item Channel-Adaptive DINO ViT-L/16 on native $w1\ldots w6$ using its Bag-of-Channels input.
\end{enumerate}
The second is a mapping-free diagnostic rather than a backbone leaderboard.

\subsection{Seed-0 matched kill comparison}
Only a competent substrate licenses three seed-0 runs: the original encoder, one middle-block
dense-wide model, and one middle-block learned MoE with eight experts, top-1 token routing, a
cosine router, and global load balancing. Dense-wide and MoE have the same total parameter count
within 0.1\%, the same data order, optimizer, schedule, training steps, classifier, and validation
calls. We also report active parameters, throughput, memory, ID accuracy, and the ID--OOD gap.

The primary estimand is
\[
  \Delta_{\mathrm{conditional}} =
  \operatorname{Acc}_{\mathrm{OOD\mbox{-}val}}(\mathrm{MoE})-
  \operatorname{Acc}_{\mathrm{OOD\mbox{-}val}}(\mathrm{dense\mbox{-}wide}).
\]
If seed-0 gain is at least five percentage points with at most a two-point ID loss, we immediately
run paired seeds 1 and 2. Otherwise no architecture grid is launched. A replicated 10--15 point
gain is the target; a smaller gain requires consistent per-experiment effects and mechanism
evidence.

\subsection{Expansion and confirmatory gate}
Only after replication do we construct multiple cell-type-stratified held-out-experiment folds and
a fixed 4/8/16/32-training-experiment curve. These tests ask whether conditional gain increases
with batch heterogeneity. Architecture and analysis are then frozen before fresh confirmatory seeds
and the first OOD-test evaluation.

\subsection{Metrics and inference}
We report OOD-validation accuracy, worst-experiment accuracy, ID accuracy, training accuracy, and
the ID--OOD gap. Paired per-experiment differences and a cluster bootstrap over experiments quantify
uncertainty. Gradient-conflict and routing analyses are interpreted only after a valid matched
predictive contrast.
